# 부동산 정책·상품·금리 출처 — 우선순위 · 화이트리스트 · 신선도

`real-estate-researcher` 에이전트가 쓰는 참조표다. `real-estate-advisor/docs/data-sources.md`
§1·§3·§5와 `.claude/agents/real-estate-researcher.md`의 출처 우선순위를 그대로 옮겼다 —
그 프로젝트가 이미 잘 설계해 둔 표를 재발명하지 않는다. **원본은 별도 저장소라 자동으로
동기화되지 않는다** — 원본이 바뀌면 이 파일도 손으로 맞춘다.

## 출처 우선순위 10단계

```
1. 정부·지자체 공식 문서
2. 국가법령정보센터 (law.go.kr)
3. 금융위원회 (fsc.go.kr)
4. 국토교통부 (molit.go.kr)
5. 금융감독원 (fss.or.kr)
6. 한국주택금융공사 HF (hf.go.kr)
7. 주택도시기금 (nhuf.molit.go.kr)
8. 공공기관 — LH·SH·HUG·GH
9. 금융회사 공식 페이지
10. 신뢰할 수 있는 언론
```

블로그·커뮤니티·유튜브는 근거로 쓰지 않는다. 단서로만 쓰고, 위 목록의 출처로 확인해야
`FACT`가 된다. **토지거래허가구역은 지자체 고시가 1차 출처다.** 국토부 자료나 언론 보도는
요약일 수 있으므로 그것만으로 확정하지 않는다.

## sourceType → confidence 매핑

| sourceType | 조건 | confidence |
|---|---|---|
| `LAW`, `GOVERNMENT` | 1차 자료 직접 확인, TTL 이내 | HIGH |
| `PUBLIC_INSTITUTION` | 공고문·상품 안내 원문 | HIGH |
| `MARKET_DATA` | 국토부 실거래가 API | HIGH |
| `BANK` | 은행 공식 상품 페이지 | MEDIUM |
| 위 출처인데 일부 조건을 추정 | | MEDIUM |
| `NEWS` 단독 | | LOW |
| TTL 초과 | 출처 무관 | LOW (재확인 필요 표시) |

## 신선도(TTL) — 재확인 주기

```
은행 금리          24h
정부 정책          24h
규제지역 지정      24h
실거래가           24h
공공주택 공고      12h
법령               7d
정적 자격 규정      7d
```

재확인에 실패하면 캐시(직전 확인 결과)를 쓰되 `confidence`를 한 단계 낮추고 "N일 전 확인
기준"을 사용자에게 표시한다. **조용히 오래된 값을 새 값처럼 쓰지 않는다.**

## 조사 우선순위 (신규 데이터 출처를 찾을 때)

```
1. 공식 API
2. 공공데이터포털 (data.go.kr)
3. 공식 웹페이지 (검색 + fetch)
4. 검색
5. 스크래핑   ← 최후 수단, robots.txt·이용약관 확인 없이 하지 않는다
```

API가 없다는 이유만으로 스크래핑하지 않는다 — 위 4단계를 다 확인했다는 근거가 있어야 한다.
스크래핑 조건이 안 되면 "사용자가 직접 확인" 안내로 대체한다 (예: 등기부등본 →
인터넷등기소).

## 이 표가 다루지 않는 것

계좌·자산 연동, 실제 대출 승인 심사, 개인 신용정보, 등기부등본 원문 조회 — `real-estate-advisor`
자신도 조회하지 않는 영역이고, `real-estate-researcher`도 조회하지 않는다.
