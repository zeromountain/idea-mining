# 한국 종목 전용 규칙

## 데이터 확보

시세는 Yahoo(`005930.KS` / `.KQ`), **재무제표와 공시는 DART OpenAPI(Tier 1)**로 조회한다.
`DART_API_KEY` 환경변수가 있으면 자동으로 켜지고, 없으면 WebSearch 폴백 안내가 나온다.

```bash
python3 $S/fetch.py financials 005930.KS   # DART fnlttSinglAcntAll (연결/CFS)
python3 $S/fetch.py filings 005930.KS      # DART 공시목록 (최근 12개월)
```

DART는 **6자리 종목코드가 아니라 8자리 고유번호(corp_code)**로 조회한다. `dart.py`가
`corpCode.xml`(상장사 약 4,000개)을 30일 캐시해 자동 변환하므로 신경 쓰지 않아도 된다.

키가 없을 때만 WebSearch로 채우되, 출처 2곳 이상 교차확인 + `confidence: low` + 회계기준
(연결/별도) 명시를 강제한다.

## 계산 규칙 (스크립트가 이미 처리한 것)

- **ROE는 지배주주 기준**으로 계산된다. `profitability.roeBasis`가 `controlling`이면
  지배주주순이익 ÷ 지배주주지분이다. 연결 기준으로 계산하면 지주회사·자회사 다수 보유 기업에서
  ROE가 부풀려진다. `controllingInterest.minorityShareOfIncome`으로 비지배지분 비중을 확인한다.
- **시가총액은 보통주 유통주식수(발행 - 자기주식) 기준**이며 우선주를 포함하지 않는다.
  `shares.preferredIssued`에 우선주 수가 따로 있다. 우선주까지 포함한 시총을 인용하려면
  그 사실을 명시한다.
- **연결(CFS) 기준**으로 가져온다. 별도재무제표와 섞어 비교하지 않는다.
- ROIC의 세율은 22%(한국 실효세율 근사)를 쓴다 — `ASSUMPTION`이다.
- 결산월은 기업개황(`acc_mt`)에서 읽어 회계연도 종료일을 만든다. 3월 결산사도 정상 처리된다.

## 판단 규칙

- **우선주를 본주와 혼동하지 않는다.** 005930(삼성전자)과 005935(삼성전자우)는 다른 종목이며
  배당수익률과 괴리율이 다르다. 사용자가 어느 쪽을 말하는지 애매하면 확인한다.
- **지주회사 할인**: 지주사는 순자산가치(NAV) 대비 30~50% 할인 거래가 구조적으로 정상이다.
  PBR이 낮다는 이유만으로 저평가라고 쓰지 않는다.
- **공시 시차**: 분기보고서는 분기 종료 후 45일, 사업보고서는 90일 이내다. `fiscalYear` 필드가
  최근 연도가 아니면 아직 공시 전이라는 뜻이므로 그 사실을 적는다.
- **환율**: 수출 비중이 높은 기업은 원/달러가 실적의 주요 변수다.
  `macro.json`의 DTWEXBGS는 달러인덱스이지 원/달러가 아니다 — 원/달러는 WebSearch로 별도 확인한다.
- **사이클**: 반도체·조선·화학·철강은 사이클 산업이다. PER이 낮을 때가 고점, 높을 때가 저점인
  역설이 흔하다. Valuation Analyst는 이 점을 반드시 다룬다.
  (예: 삼성전자 FY2023 영업이익 6.6조 → FY2025 43.6조)
- 액면분할·무상증자 이력이 있으면 과거 주가·EPS 비교 시 조정 여부를 확인한다.

## 리포트 표기

통화를 항상 명시한다 (`281,500원`, `$214.72`). 원화 금액은 조·억 단위로 읽기 쉽게 쓰되
괄호에 정확한 숫자를 남긴다.
