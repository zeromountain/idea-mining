# ETF·포트폴리오 분석

## 투자 성향이 없으면 비중을 말하지 않는다 (문서 §30, §70)

`~/stock-research/profile.json`이 없으면 **구체적 비중이나 금액을 제시하지 않는다.**
대신 관찰된 집중도와 리스크만 알리고, 판단에 필요한 정보를 밝힌다.

필요한 항목: 투자 기간 · 위험 감내도 · 감내 가능한 최대 낙폭 · 월 투자금액 · 현재 자산 · 현금 필요 시점.

사용자가 원하면 `AskUserQuestion`으로 받아 `profile.json`에 저장한다. 받기 전까지
`positionSizingWithheld: true`로 표시하고 리포트에도 그 사유를 적는다.

`~/stock-research/profile.blocked.json`이 있으면(wealth-manager 플러그인이 재무 안정성
게이트 위반으로 profile 기록을 거부한 경우) `profile.json`이 있어도 없는 것으로 취급해
`positionSizingWithheld: true`를 유지하고, `reasons[].unblockCondition`을 리포트에
그대로 옮긴다 — "안 됩니다"가 아니라 "이 조건이면 됩니다"로 보여준다.

## ETF는 개별 종목 파이프라인을 쓰지 않는다

해자·경영진 분석은 ETF에 의미가 없다. 대신 본다:

- 상위 보유종목 10개와 비중 (운용사 페이지 WebFetch)
- 섹터 구성
- 보수율(TER)
- 추적 대상 지수와 추적오차
- **다른 보유 ETF와의 구성 중복** — VOO ∩ QQQ는 시가총액 상위 기술주에서 크게 겹친다
- 배당수익률과 분배 주기

DCF는 하지 않는다. Rating을 낼 때는 개별 종목과 같은 밴드를 쓰되,
`business`/`moat` 대신 `구성 품질`과 `비용`을 평가 항목으로 대체하고 그 사실을 명시한다.

## 포트폴리오 분석 항목 (문서 §29)

| 항목 | 방법 |
|---|---|
| 섹터 집중도 | 종목별 섹터를 합산. 한 섹터 40% 초과면 지적 |
| 단일 종목 리스크 | 개별 종목 비중 + 그 종목의 변동성(`atrPct`) |
| 실질 중복 | ETF 구성종목까지 펼쳐서 계산. "VOO 40% + NVDA 15%"는 NVDA 실질 노출이 15%보다 크다 |
| 성장/가치 노출 | 보유 종목의 밸류에이션 배수 가중평균 |
| 상관관계 | 같은 섹터·같은 매크로 민감도를 공유하는지 정성 판단 |
| 변동성·낙폭 | 종목별 `returns`와 `atrPct`로 근사. 정밀 계산은 하지 않고 근사임을 밝힌다 |

## 절차

1. 각 종목을 `fetch.py quote`로 조회한다 (전체 deep 분석을 돌리지 않는다 — 비용 낭비).
2. 비중이 큰 종목(10% 초과)만 추가로 `financials`를 확보한다.
3. 실질 중복을 계산한다. ETF 구성은 WebFetch로 상위 보유종목을 가져온다.
4. 관찰 결과를 제시한다. **처방이 아니라 관찰이다** — profile.json이 없으면 특히 그렇다.

## 흔한 실수

- "분산이 잘 되어 있다"를 종목 개수로 판단하기 (같은 팩터면 개수는 무의미하다)
- ETF를 "안전자산"으로 분류하기 (QQQ는 고베타 성장주 집중이다)
- 사용자가 묻지 않은 리밸런싱을 지시하기
