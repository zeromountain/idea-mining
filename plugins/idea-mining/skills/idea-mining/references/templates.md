# 소규모 세무사무소용 거래 자동분류 정확도 개선 도구

## 문제
- **누가**: 월 100건 이하 처리하는 1인·소규모 세무사무소
- **언제**: 매월 마감 시 거래 내역을 회계 SW에서 불러온 직후
- **왜 아픈가**: 잘못 분류된 항목을 하나하나 재확인하느라 건당 10~15분 추가 소요, 월 15~20시간
- **지금은 어떻게 버티나**: 엑셀에 규칙을 따로 만들어 수작업 대조
- **왜 아직 안 풀렸나**: 대형 회계 SW는 대량 고객 대상 범용 모델이라 업종별 미세조정을 안 함

(E1, 출처: https://example.com/review-thread, 확인일 2026-08-05) 관련 커뮤니티 스레드에서 동일 불만 다수 발견 — "매달 30건 넘게 손으로 다시 고친다"는 원문 인용.
(E3) 소규모 사무소일수록 업종이 몰려 있어 미세조정 여지가 클 것으로 보임 — 미검증 추론.

## 기존 대안
- **A사 회계 SW의 자동분류**: 이미 쓰고 있는 것 자체. 범용 모델이라 업종별 정확도가 낮음 — 충분하지 않은 이유.
- **B 서비스(범용 규칙 엔진)**: 규칙을 직접 짜야 해서 비개발자인 세무사에게 진입장벽이 높음 — 충분하지 않은 이유.

## 해법 (선택된 것)
기존 회계 SW에 플러그인으로 붙는, 업종별 규칙 학습형 분류 보조 도구.

## 프리모템 요약
- 세무사가 기존 SW를 바꾸지 않고 플러그인만 추가로 신뢰하지 않을 위험 → 기존 SW 안에서 동작하는 형태로 완화
- 업종별 규칙이 실제로는 사무소마다 달라 일반화가 안 될 위험 → 최소 검증 실험에서 확인 예정

## 스코어
| 항목 | 점수 |
|---|---|
| 문제 강도 (×2) | 5 |
| 본인 적합도 | 3 |
| 검증 속도 | 5 |
| 차별성 | 4 |
| 유통 경로 확보 (business) | 3 |
| 유닛 이코노믹스 sanity (business) | 4 |
| **합계** | **22 + 도메인 7** |

상대 순위: 이번 세션 후보 3개 중 1위 (2위 대비 "첫 100명을 어디서 찾나"에 대한 답이 구체적이라는 점에서 우위).

## 검증 계획
- **가장 위험한 가정**: 세무사가 이 불편 때문에 실제로 별도 유료 도구를 도입할 의향이 있다 (지금은 그냥 참고 있을 수도 있음)
- **최소 검증 실험**: 세무사 커뮤니티에 문제 설명 + 관심도 조사 게시, 5명 인터뷰
- **kill 조건**: 인터뷰 5명 중 3명 이상이 "그 정도는 감수할 만하다"고 답하면 접는다

## 세션 로그 (`~/ideas/sessions/YYYY-MM-DD-<topic>.md`)

탈락한 해법까지 전부 남긴다. 오늘 버린 게 나중에 맞는 답이 되는 경우가 흔하기 때문이다.

```markdown
# 세션: 2026-08-05 — 세무사무소 SaaS 아이디어 발굴 (깊은 모드)

## 스코핑
- 영역: 신규 사업/서비스
- 재료 소스: 웹 리서치 + 모델 지식 (병렬 서브에이전트 2개)
- 제약: 초기 예산 없음, 1인 개발
- 성공 기준: 바로 검증 시작할 것 1개

## 발굴된 문제 (전체)
1. ...
2. ...

## 발산된 해법 (선택 안 된 것 포함)
### 문제: 거래 자동분류 정확도
- 해법 A (선택됨, 유추 전이 기법): 플러그인형 분류 보조 도구 → `~/ideas/2026-08-05-tax-autocategorize.md`
- 해법 B (탈락, 점수 12, 제약 주입 기법): 완전히 새 회계 SW 자체 개발 — 진입장벽이 너무 높다고 판단
- 해법 C (탈락, 점수 9, 극단 사용자 기법): 세무사 대상 컨설팅 서비스 — 확장성 낮음

## 기존 해결책 사전 조사
- A사·B서비스 확인 — 둘 다 "충분하지 않은 이유"를 해법 A 파일에 기록 (`evidence.md` 절차)

## 비평 (해법 A)
- 프리모템: 실패 원인 5개 중 "기존 SW 신뢰 이탈 저항"이 가장 치명적으로 판단, 플러그인 형태로 완화
- 독립 레드팀(서브에이전트, 맥락 차단): "업종별 규칙 일반화 안 될 수 있음" 반박 — 부분적 반박으로 판단, 검증 실험에 반영

## 저장된 아이디어
- 2026-08-05-tax-autocategorize.md
```
