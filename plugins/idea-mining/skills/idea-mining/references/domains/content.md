# 도메인: 콘텐츠/마케팅

좋은 소재를 찾는 게 아니라 **유통 가능하고 반복 가능한** 소재를 찾는 것이 핵심이다. 아무리 좋은 글도 볼 사람에게 닿지 못하면 존재하지 않는 것과 같다.

## 필수 질문

- **이 주제로 이미 쓴 사람 대비 내가 더할 관점은**: 검색하면 나오는 기존 콘텐츠와 똑같은 이야기를 반복하는 게 아닌지. 관점이 없으면 소재가 아무리 좋아도 묻힌다.
- **어디에 올리나**: 구체적인 채널(어느 커뮤니티, 어느 플랫폼, 어느 뉴스레터)을 지목할 수 있어야 한다. "일단 블로그에"는 유통 계획이 아니다.
- **읽고 나서 뭘 하게 되나**: 정보 습득만으로 끝나는지, 행동을 유발하는지(저장, 공유, 문의, 구매). 목적에 따라 형식과 CTA가 달라진다.

## 추가 점수 항목 (공통 4항목에 더함, `scoring.md` 참고)

- **유통 채널 보유 여부**: 이미 팔로워·구독자·커뮤니티 지분이 있는 채널에 맞는가, 아니면 새로 채널을 키워야 하는가
- **검색·수요 신호**: 관련 키워드의 실제 검색량·질문 빈도 (웹 리서치로 확인, `evidence.md`의 증거 등급 적용)
- **시리즈화 가능성**: 1회성 소재인지, 반복 포맷으로 우려낼 수 있는지 — 반복 가능한 쪽이 채널 성장에 유리
- **관점 차별성**: 같은 주제의 기존 콘텐츠 대비 실질적으로 다른 각도인지 (표면적 재구성이 아닌지)

## 흔한 실패 패턴 (비평 단계 체크리스트)

- **검색 수요만 보고 관점 없음**: 키워드 수요는 확인했지만 남과 다르게 말할 거리가 없음
- **유통 없이 생산**: 콘텐츠 기획은 상세한데 누구에게 어떻게 도달시킬지는 없음
- **1회성 소재**: 반복 포맷으로 만들 수 없어 매번 처음부터 기획해야 함
- **채널-형식 불일치**: 짧은 소비가 어울리는 채널에 긴 형식을, 혹은 그 반대를 넣음

## 최소 검증 실험 예시

- 소재를 짧은 포스트/스레드로 먼저 테스트해 반응(저장·댓글·공유) 확인
- 관련 커뮤니티에 질문 형태로 먼저 던져 관심도 가늠
- 제목/후크 3안을 만들어 어느 게 더 클릭되는지 소규모 테스트
- 검색 키워드 도구로 실제 검색량과 경쟁 콘텐츠 품질 확인
